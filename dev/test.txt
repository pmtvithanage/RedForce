
1. First, let's check and fix the directory permissions:

# Navigate to your project directory
cd /Applications/XAMPP/xamppfiles/htdocs/RedForce/

# Check current permissions
ls -la public/

# Fix permissions for the uploads directory
sudo mkdir -p public/uploads/advertisements
sudo chmod -R 755 public/uploads
sudo chown -R $(whoami) public/uploads
sudo chown -R daemon public/uploads  # XAMPP usually uses 'daemon' user

# Verify the permissions
ls -la public/uploads/
