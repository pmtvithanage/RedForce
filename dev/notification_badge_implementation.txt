CLIENT REQUESTS NOTIFICATION BADGE - IMPLEMENTATION COMPLETE
=================================================================

OVERVIEW:
Implemented a notification badge on the Client Requests button that
displays the count of PENDING service requests. The badge appears at
the top-right corner of the button and includes a hover effect.

=================================================================
FILES MODIFIED:
=================================================================

1. app/controllers/Admin.php
   CHANGE: Modified clients() method
   - Added call to getServiceRequestStats()
   - Passes pendingRequestsCount to view
   - Only counts PENDING requests (not approved/rejected)

2. app/views/admin/v_clients.php
   CHANGE: Modified Client Requests stat card
   - Removed stat-value div (no more number inside card)
   - Added notification badge with conditional display
   - Badge only shows if pendingRequestsCount > 0
   - Added "client-requests-card" class for styling

3. public/css/admin/clients_style.css
   ADDITIONS: Added notification badge styles
   - .client-requests-card - Cursor pointer and transition
   - .client-requests-card:hover - Lift effect with shadow
   - .notification-badge - Red badge with number
   - @keyframes pulse - Subtle pulsing animation

=================================================================
HOW IT WORKS:
=================================================================

BACKEND FLOW:
1. Admin visits /admin/clients page
2. Admin controller calls getServiceRequestStats()
3. Extracts pending count from stats
4. Passes count to view as $data['pendingRequestsCount']

FRONTEND DISPLAY:
1. If pendingRequestsCount > 0:
   - Red notification badge appears at top-right corner
   - Shows number of pending requests
   - Badge pulses gently to attract attention

2. If pendingRequestsCount = 0:
   - No badge is shown
   - Button appears normal

3. Hover effect:
   - Card lifts up slightly (translateY -4px)
   - Pink shadow appears
   - Smooth 0.3s transition

BADGE STYLING:
- Position: Absolute top-right (8px from edges)
- Background: Red gradient (#ef5350 → #e53935)
- Size: Min 24px circle, expands for larger numbers
- Font: 14px, bold, white text
- Shadow: Soft red glow
- Animation: Subtle pulse every 2 seconds
